## httpClientV4

The program loops and send a http request in each loop. The http request are formed from input lines.
Key parameters are:
 - the http method: the program can send the following commands: GET/POST/PUT/DELETE/HEAD/CONNECT/OPTIONS/TRACE/PATCH
 - response body: the message mime type limited to "text/plain"
